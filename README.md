# Biomedical Research & Data Science Portfolio

I am a biomedical researcher interested in **clinical data science, reproducible research, neuroimaging-oriented workflows, and machine learning for translational research**.

This profile highlights compact technical projects designed to make analytical methods transparent, reproducible, and easy to audit. The featured portfolio projects use **synthetic data only** and are presented as technical demonstrations rather than clinical validation studies.

## Featured projects

### 🧠 [MRI Feature Pipeline](https://github.com/sebastian280800-cyber/mri-feature-pipeline)
A reproducible Python demonstration for synthetic 3D brain-MRI generation, preprocessing, quality control, and quantitative region-level feature extraction.

**Methods:** Python · NumPy · 3D image arrays · NIfTI-oriented workflows · quantitative features · automated QC

### ⚡ [Neuromodulation Outcome ML](https://github.com/sebastian280800-cyber/neuromodulation-outcome-ml)
A synthetic-data demonstration of clinical + imaging-derived feature modeling for a neuromodulation-oriented response endpoint.

**Methods:** scikit-learn · leakage-aware preprocessing · cross-validation · ROC/AUC · calibration · permutation importance

### 🔬 [Reproducible Biomedical Pipeline](https://github.com/sebastian280800-cyber/reproducible-biomedical-pipeline)
An auditable biomedical-research workflow with data validation, missingness QC, automated analysis outputs, file hashing, run manifests, and unit tests.

**Methods:** pandas · reproducibility · QA/QC · automated reporting · SHA-256 provenance · pytest

## Technical approach

- Build **reproducible analysis pipelines** rather than one-off scripts
- Keep assumptions, preprocessing, and data provenance explicit
- Separate raw inputs, derived outputs, and analysis code
- Use leakage-aware model evaluation and transparent performance metrics
- Add automated QC and tests where possible
- Keep public repositories free of patient-identifiable or confidential data

## Current focus

I am expanding my technical work at the intersection of **clinical research, quantitative neuroimaging, neuromodulation, and translational machine learning**.

## Portfolio note

The highlighted repositories are intentionally built with synthetic data so that the complete workflows can be shared publicly without exposing protected health information, confidential datasets, or unpublished patient-level research data.
